# @core-circle/ui

A high-performance, accessible, and beautifully designed component library built for the next generation of Core Circle applications.

## Installation

Install the package via the GitHub Packages registry:

```bash
npm install @core-circle/ui
```

> **Note**: Ensure you have configured your `.npmrc` to point `@core-circle` to the GitHub Packages registry.

## Features

- **TypeScript First**: Built with strict type-safety for a better developer experience.
- **Tailwind CSS v4**: Optimized for the latest styling engine for maximum performance.
- **Modern Aesthetics**: Vibrant colors, sleek dark modes, and smooth micro-animations.
- **Accessible**: Built with a focus on web accessibility (a11y).

## Usage

```tsx
import { Button } from '@core-circle/ui';

export default function App() {
  return (
    <Button variant="primary" size="md">
      Click Me
    </Button>
  );
}
```
